# Make the homepage a learning directory

## Context

The first homepage gave most of its visual space to the completed hstring project. That made the site read like a project showcase even though the site is intended to organize several kinds of learning content.

## Decision

The homepage is a general guide to the site. It presents the three learning directions—编程相关知识、编程相关项目、科研类内容—and links to the knowledge index. Project-specific visual entries live on category pages. The 编程相关项目 page reuses the title-plus-diagonal-string entry pattern first validated by the HString page.

## Consequences

New projects can be added to a category page without redesigning the homepage. HString remains accessible and keeps its historical-source boundaries, but it no longer defines the homepage hierarchy. Empty categories can exist as explicit “准备中” pages until their first entry is ready.
